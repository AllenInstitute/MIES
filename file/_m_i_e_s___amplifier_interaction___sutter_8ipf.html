File MIES_AmplifierInteraction_Sutter.ipf¶

AI_SU Interface with the amplifiers integrated in the Sutter IPA devices

The amplifier headstages are addressed by their probe index, which is the zero-based index of the headstage over all IPA devices in the order of LISTOFDEVICES from GetSUDeviceInfo(). The MIES headstage with the same index is fixed to that amplifier headstage.

Todo:

Add GUI controls to the DAEphys panel for the Sutter amplifier settings primary output low pass filter, gain and dynamic hold. Contrary to MCC amplifiers there is no amplifier control software for these settings. The filter can currently only be set via AI_WriteToAmplifier() with MCC_PRIMARYSIGNALLPF_FUNC, gain and dynamic hold only via the IPA_Control API. All three are stored in the labnotebook. The controls require a DAEphys panel version bump and support in the configuration save/restore code, see https://github.com/AllenInstitute/MIES/issues/2790.

Gains of the Sutter headstages

The Sutter XOP outputs and acquires the headstage signals in SI units, independent of the gain setting of the amplifier.

mV/V, command in V

static const double SUTTER_VC_AD_GAIN = 1e-12¶

A/pA, current in A.

static const double SUTTER_IC_DA_GAIN = 1e12¶

pA/A, command in A

static const double SUTTER_IC_AD_GAIN = 1e-3¶

V/mV, voltage in V.

static std::tuple<string, variable, variable> AI_SU_GetSetting(variable func, variable clampMode)¶

Return the IPA control keyword and the scale factors for the given amplifier function.

The value for the IPA control package is value * prefixScale * unitScale, where value is in MIES units (see usePrefixes of AI_SendToAmp()), prefixScale converts from MIES units to SI units and unitScale from SI units to the unit of the IPA control package.

Parameters:

  • func – Function to call, see AI_SendToAmpConstants

  • clampMode – V_CLAMP_MODE or I_CLAMP_MODE

Returns:

keyword, empty if the function is not supported by the Sutter amplifiers
